# КАЗИК

Игровой зал с тремя браузерными мини-играми на виртуальные очки: Плинко, кости, орёл и решка. У всех игр общий баланс и отдельная история последних раундов. В профиле можно изменить имя и посмотреть статистику.

Открой `index.html` в браузере или разверни корень репозитория на статическом хостинге. Сборка и сервер не нужны.

Новый профиль получает 1000 виртуальных очков. Баланс, профиль и результаты хранятся в браузере. Баланс Плинко из предыдущей версии подхватывается автоматически, если сайт открыт по тому же адресу в том же браузере. Счётчик раундов и рекорд выплаты ведутся с версии игрового зала.
