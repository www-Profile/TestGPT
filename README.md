# Плинко

Мини-игра на виртуальные очки. Выбери стоимость броска, разброс множителей и число рядов. Шарик с равной вероятностью отклоняется влево или вправо в каждом ряду. Итоговая ячейка определяет, сколько очков вернётся после броска.

Игра работает в браузере без сборки, сервера и внешних зависимостей. Открой `index.html` или разверни корень репозитория на статическом хостинге.

Баланс и последние восемь бросков сохраняются в браузере. Кнопка «Начать заново» возвращает 1000 очков. Пробел запускает бросок, когда фокус находится вне элементов управления.
