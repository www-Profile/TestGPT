# Comuni

Веб-мессенджер с комнатами по ссылке, текстовыми сообщениями в реальном времени и историей в SQLite.

## Запуск

Нужен Node.js 24 или новее. Из каталога `comuni` запусти:

```sh
node server.mjs
```

Открой http://localhost:3000. Для проверки открой ссылку на комнату в двух браузерах или в обычном и приватном окнах. Имя можно изменить через профиль.

По умолчанию сообщения хранятся в `data/comuni.sqlite`. Для переноса базы на постоянный диск можно задать каталог через `COMUNI_DATA_DIR`, а порт можно изменить через `PORT`.

Общий чат открыт всем пользователям экземпляра. Остальные комнаты доступны любому, у кого есть ссылка. Имена задаются без регистрации и не подтверждают личность. В этой версии нет сквозного шифрования. Для использования через интернет нужен HTTPS и хостинг с постоянным диском и поддержкой Server-Sent Events.
